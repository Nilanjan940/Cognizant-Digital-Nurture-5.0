# Assignment 1: Setup C# Development Environment

## Objective

Set up the C# development environment and verify that a basic C# console application can be created and executed successfully.

## Requirements

- Latest .NET SDK
- Visual Studio 2022 / Visual Studio Code
- C# Extension
- Terminal / Command Prompt

## Concepts Covered

- .NET SDK installation
- C# Console Application
- Project creation using CLI
- Main() method
- Compilation and execution of C# programs

## Steps

1. Install .NET SDK.
2. Verify installation.
3. Create a new console application.
4. Write a Hello World program.
5. Build and execute the application.

Run:

```bash
dotnet new console -n HelloWorldApp
